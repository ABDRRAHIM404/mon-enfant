# Admin interface update

The admin area now has a shared navigation shell, a genuine overview, clearer verification queues and review forms, compact professional cards, French permission labels, and consistent catalogue/account screens. Admin skeletons retain the navigation while loading.

Existing reviewer, clinical-manager and catalogue permissions remain separate. Evidence privacy, reason requirements, decision history and clinical record boundaries are preserved. No new admin access was granted.

Source tests, types and lint pass. The shared browser requires an existing admin sign-in before authenticated visual/interaction review can finish. See [review and limits](docs/design-qa/admin-ui/review.md).
